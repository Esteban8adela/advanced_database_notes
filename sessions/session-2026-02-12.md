# Session – 2026-02-12

## Topics covered
- Basic SELECT queries: Fetching specific columns vs. all columns using the asterisk (*) wildcard.

- Filtering data (WHERE): Applying constraints to numeric data (=, <, >, BETWEEN) and text data (!=).

- Text pattern matching: Using the LIKE operator and the % wildcard for partial string matches.

- Removing duplicates: Using the DISTINCT keyword to return only unique values.

- Sorting results (ORDER BY): Arrangely rows alphanumerically in Ascending (ASC) or Descending (DESC) order.

- Limiting and Paginating (LIMIT & OFFSET): Restricting the number of rows returned and skipping a specific number of rows before returning the results.

## What I understood
- I know how to structure a basic SQL query to pull exactly the data I want from a single table.

- I can use WHERE combined with LIKE and % to find text even when I don't know the exact string.

- I understand how to combine ORDER BY, LIMIT, and OFFSET to create "Top X" lists or mimic page-by-page website navigation.
