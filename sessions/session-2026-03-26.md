- Using Oracle pseudocolumns (USER, SYSDATE) to automate audit trails.

## What I understood
- How to automatically populate tracking columns (like UPDATE_DATE and UPDATED_BY_USER) the moment a row is inserted.
- How to compare the current USER with the :OLD row values to restrict UPDATE privileges strictly to the original record creator.
