## What I understood
- OLTP: This one is all about inserting data efficiently. Keeping things properly normalized is super important here.
- OLAP: This is your go-to for reading data and getting fast results. It uses simpler queries, avoids messy database joins by just having more columns, but it's definitely not the best choice if you need to write or update data a lot.
- Star Schema: Picture a main, centralized table sitting right in the middle, with a bunch of other tables linked around it—literally shaped like a star.
- ETL: The whole data pipeline. You grab the data from a source (Extract), clean or change it up (Transform), and then drop it into its final target destination (Load).
