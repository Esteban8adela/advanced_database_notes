## Topics covered

## What I understood
- Window Functions for Ranking: I learned how to use DENSE_RANK() OVER (PARTITION BY ... ORDER BY ...) to assign a rank to employees based on their salary within their specific department.

- Handling Ties: DENSE_RANK() is the right choice here over RANK() or ROW_NUMBER() because it ensures that if multiple employees share the same salary (like James and Amelia earning 4000), they get the same rank, and the next salary in line doesn't skip a rank number.

- Order of Execution: I must wrap the window function in a subquery (or CTE) because SQL does not allow window functions to be directly used in a WHERE clause.
